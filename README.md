# Travel Explorer --- Landing Page

#Опис проєкту

**Travel Explorer** --- це адаптивний лендинг туристичної компанії,
створений на чистому **HTML, CSS та JavaScript**.\
Проєкт демонструє сучасний дизайн, зручну навігацію та базову
інтерактивність через бургер-меню.

## 📂 Структура проєкту

    /
    ├── index.html      # Основна сторінка
    ├── styles.css      # Стилі
    └── script.js       # Логіка мобільного меню

 Основні можливості

-   Адаптивна верстка (desktop / tablet / mobile)
-   Сучасний UI з сітками (CSS Grid)
-   Мобільне навігаційне меню (бургер)
-   Вбудовані зображення (base64) та зовнішні зображення
-   Чітка структура секцій

 Технології

-   HTML5
-   CSS3 (Grid, Flex, Media Queries)
-   Vanilla JavaScript
